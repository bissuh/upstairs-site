# Upstairs — website

The public pages for [Upstairs](https://apps.apple.com/app/id6799127731), a PST and OST
mail-archive viewer for iPad and Mac.

- `index.html` — what the app does
- `privacy.html` — privacy policy (the App Store's Privacy Policy URL)
- `support.html` — support (the App Store's Support URL)

Static, no scripts, no external requests, light and dark. Source for the app itself is
kept separately.
