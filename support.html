Support

Email support@tecnosolve.com and you will get a reply from a person. Most answers are below.

Before you write

If an archive will not open, the error message on screen names the specific reason. Including that exact wording in your email will usually get the problem solved in one reply instead of three.

Please do not send us your archive. It is your mail, we have no secure way to receive it, and we do not want a copy. If we need to reproduce something, we will ask you for the error text and the file's size and origin — never its contents.

Opening archives

Try a sample archive

If you are not sure whether the problem is your file or the app, open this one: demo-archive.pst (16 KB). It is a small mailbox of entirely invented correspondence — three folders, eleven messages, covering plain text, HTML and formatted bodies, with attachments. Nobody in it is real.

If the sample opens and reads correctly and your own archive does not, the error message on screen tells us which of the cases below you have hit.

On iPad or iPhone: tap the link, then Download, then find the file under Downloads in the Files app. In Upstairs, tap Open Archive… and choose it.

"This archive uses the older ANSI format"

The file was made by Outlook 97–2002, which used a different 32-bit layout. Upstairs does not read it yet. If you still have access to a Windows PC with Outlook, opening the file there and exporting a new .pst produces the modern Unicode format, which Upstairs does read.

"This OST uses 4 KB pages"

Outlook 2013 and later write .ost files with a page layout Upstairs does not parse yet. It refuses by name rather than showing you a mangled archive. This is a known gap and is on the list to fix.

The file is password-protected

Archives protected with a password set inside Outlook cannot be opened without it, and Upstairs will not attempt to guess or bypass one.

A file I opened before now says it cannot be found

It was moved, renamed, or is on a drive that is not connected. Open it again from Open Archive… and the entry will start working again.

Reading and searching

A message body is empty

Some messages genuinely have no body — calendar invitations and read receipts, for instance. If a message that should have text renders blank, that is a bug we want to hear about. Tell us roughly what it was (an HTML newsletter, a plain reply, a forwarded chain) and which version of Outlook the archive came from.

Search does not find something I can see

Indexing runs in the background when an archive is first opened, and search only covers what has been indexed so far. On a large archive give it a few minutes. Accents and case are ignored deliberately, so cafe matches café.

Images are not loading

That is deliberate. Remote images are blocked until you press Load Images, because loading one tells the sender's server that you opened the message. The banner at the top of the message is the switch.

Export

Where do exported messages go?

You choose the destination when you export. Files are written as .eml, which Mail, Thunderbird and most other mail clients open directly. Attachments can be saved separately, and a whole folder can be exported at once.

Export is greyed out

Export is a Premium feature. See below.

Free tier and Premium

What is free?

Browsing your folders and searching the whole archive are unlimited and free, permanently. The free tier opens ten messages a day.

What does Premium add?

It removes the daily limit and unlocks export. It is a single one-time purchase — there is no subscription, and one purchase covers your Mac, iPad and iPhone using the same Apple Account. It is also family-shareable.

Is there a subscription?

No. You buy Premium once and it stays unlocked, including on devices you buy later. Most people open Upstairs because they have one archive they need to get into, and charging a recurring fee for a job you do once would be wrong.

I bought Premium but it is not active on this device

Use Restore Purchases in the app, and check the device is signed in to the same Apple Account you bought with. This is the normal way to get Premium onto a new device or after reinstalling — nothing is lost. If it still does not appear, email us with the date of purchase — not your receipt, which contains more than we need.

Refunds

Apple handles all billing, so we cannot issue a refund ourselves. Request one at reportaproblem.apple.com. There is no subscription to cancel.

Privacy

Does Upstairs send my mail anywhere?

No, and it cannot: the app ships without network permission. The privacy policy shows how to verify that yourself in one command.

Can Upstairs damage my archive?

No. Archives are opened read-only. The app has no code path that writes to them.

Reporting a bug or asking for a feature

Email support@tecnosolve.com. Useful things to include:

  • What you did and what happened instead
  • The exact error text, if there was one
  • Which device and OS version
  • Roughly how big the archive is, and which Outlook version produced it

Repeated requests for the same thing are the clearest signal we get about what to build next, so it is worth writing even if you assume someone else already has.
